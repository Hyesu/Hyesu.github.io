# 탑뷰 카메라로 프로젝트 생성
- 카메라 오브젝트 인스펙터 값 설정
    - Camera.Projection = Orthographic
        - 탑 다운으로 볼 때 왜곡을 없애기 위함    
    - Camera.Size = 보이는 화면의 절반 높이(유닛 기준)
    - Transform
        - 직교로 내려다보는 세팅
            - Position = (0, 10, 0)
            - Rotation = (90, 0, 0)
        - 45도 비틀어서 내려다보는 세팅        
            - Position = (0, 10, 0)
            - Rotation = (30, 45, 0)

# 마우스 호버되는 곳의 월드 좌표 가져오기
1. `Camara.main.ScreenPointToRay(Input.mousePosition)`을 통해 Ray를 획득
2. 획득한 Ray를 터레인에 `Pysics.Raycast`하여 히트 지점을 획득
    - Pysics.Raycast(ray, out var hit, 1000.0f, terrainMask)
    - terrainMask = LayerMask.GetMask("Terrain")
    - scene에 Layer=Terrain로 지정된 게임 오브젝트(aka.터레인)가 필요함
        - Terrain 컴포넌트 가지고 있음
        - Terrain Collider 컴포넌트 가지고 있음

# 시네머신
언리얼에서는 액터에 카메라 컴포넌트를 붙여놓고, `SetViewTarget`을 통해서 카메라 타겟을 쉽게 전환할 수 있었다. 유니티에서도 이와 같은 효과를 하는 것을 찾아보다가 시네머신(가상 카메라)라는 것이 있다고 하여 공부를 좀 해보고 적용해보자 싶음.

[유니티 독스](https://docs.unity3d.com/kr/Packages/com.unity.cinemachine@2.3/manual/CinemachineOverview.html)


## 설치
Package Manager를 통해 설치한다.

1. [Window] > [Package Management] > [Package Manager]
2. [Unity Registry] > **Cinemachine** 검색/설치


## 가상 카메라(CinemachineVirtualComponent)
- 메인 카메라 처럼 게임 오브젝트로서 씬에 배치될 수 있다.
    1. [메뉴] > [Cinemachine] > [Create Virtual Camera]
        - 또는 CinemachineVirtualComponent를 가진 게임 오브젝트

- 시네머신을 통해 두 개 이상의 가상 카메라 간의 블렌딩을 처리할 수 있다.
    - 기본적으로는 하나의 가상 카메라가 **라이브 상태**이며, 블렌딩하는 동안에는 두 개의 카메라가 라이브 상태가 된다.


## 시네머신 브레인(CinemachineBrainComponent)
- 시네머신 브레인은 씬의 모든 액티브 가상 카메라를 모니터링하는 매니징 객체
    - 가상 카메라 게임 오브젝트를 enable/disable 함으로써 라이브 상태를 전환 가능하다.
    - 여러 개를 활성화한 경우, 우선 순위가 높은 것을 선택하여 라이브 처리한다.
- Blend Settings
    - 라이브 카메라 전환시 블렌딩을 수행한다.
- Custom Blends
    - 특정 가상 카메라간의 블렌딩을 정의 가능
    - 레퍼런스가 아닌 이름을 통해 카메라를 찾음
    - 모든 가상 카메라 간에 블렌딩하려면 **ANY CAMERA**를 이름으로 사용하면 됨
- 필요시 카메라 게임 오브젝트에 유니티가 자동으로 추가하기도 함


## Advanced Topics..
- 타임라인과 함께 사용하여 컷씬에서의 카메라 전환에 이용되기도 한다고 한다.
- PIP(Picture-in-Picture) 효과에도 시네머신을 사용 가능하다고 한다.
    - [유니티 가이드](https://docs.unity3d.com/kr/Packages/com.unity.cinemachine@2.3/manual/CinemachineMultipleCameras.html)
    - 언리얼에서는 렌더타겟 따로 만들어서 카메라에 붙여 썼던 것 같은데, 만약 실제 쓰게 된다면 성능 등 확인해봐야 할 것 같음
