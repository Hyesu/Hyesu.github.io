# 부모의 크기를 자식의 사이즈로 맞추되, 자식도 자식의 사이즈에 따라 가변해야 하는 경우
게임에서는 가변적인 데이터에 의해 동적 ui를 만든는 일이 왕왕 있는데, 유니티 ui는 동적으로 영역이 커지는 것에 대하여 너무 불편하다.

가령 아래같은 구조는 만들다 보면 왕왕 나오는데 말이다.
```md
UI
- **VLG_Root**
    - Image
    - **Text_A**
    - **VLG_Child**
        - **UI_Prefab**
            - **Text_B**
        - UI_Prefab
        - UI_Prefab
```
- VLG_Root
    - 최상위 수직 그룹으로, 내부의 UI 요소들이 세로로 배치되길 원함
    - child로 속한 것들에 따라 사이즈가 늘어나길 원함
    - UMG에서는 vertical box로 간단하게 처리 가능함
- Text_A
    - 텍스트인데, 로컬라이징이나 멀티 라인 등을 고려하다보면 높이를 미리 정의하기 어려움. 두줄이 될수도 세줄이 될 수도 있는데, 라인에 따라 영역이 확보되어야 함
- VLG_Child
    - 내부 수직 그룹으로, 가변적으로 들어갈 수 있는 리스트성 배치 그룹
    - 실제 사이즈는 child로 추가되는 프리팹의 개수에 따라서 결정되어야 한다.
    - 몇개가 될 지는 모른다.
- UI_Prefab
    - 프리팹으로 만들어놓는 것인데, 내부에 또 사이즈에 따라 변경 가능한 것들이 있을 수 있다.

간단한 예시만 생각해봐도, 즐겨찾기 리스트 라든지 암튼 흔하다.

## 문제
기본적으로는 최상위 부모에게 Layout Group 컴포넌트를 추가해서 배치를 결정하고, Content Size Fitter를 적용해서 내부 사이즈에 맞게 fit하라는 것이 권장이다.

문제는 Layout Group의 child는 content size fitter를 사용하려고 하면, 경고가 표시된다는 거다. layout group이 배치하면서 사이즈를 결정하려고 하는데, content size fitter가 사이즈를 바꾸려고 하니 서로 난리난리라는 경고인듯..

결과적으로 원하는 건 child부터 차곡차곡 사이즈 결정되고 부모는 그냥 따라갔으면 좋겠는데, 뭔가 부모부터 사이즈를 딱딱 정해놓고 만들기를 바라는 것 같음.
